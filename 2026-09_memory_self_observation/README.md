# Memory self-observation

## Question

住人に過去のMemoryを現在の観察対象として提示したとき、何をするか。

Memoryの整理、Reflection、計画など特定の処理を要求せず、過去を見られる状態だけを作る。

## What was done

住人本人の直近のUtterance Memory群と、直近TALK時に保存された現在の情報を提示し、自由な応答を生成した。

この実験ではMemory自体を変更しない。生成された応答は観察用ログとして保存する。

実装は `memory_self_observation_experiment.py`、単独実行用入口は `memory_observe.py`。

## Prompt policy

最後の指示は次の一文だけにした。

> これらを見て、思ったことがあれば自由に話してください。

「整理してください」「振り返ってください」「計画してください」など、出力の用途を指定する語は入れていない。

詳細は [prompts.md](./prompts.md) を参照。

## Observed

複数回の試行では、過去のやり取りを現在から評価するような応答や、次回のやり取りに触れる応答が出た。

また一度、ステラが自発的に `【Memoryの整理・要約】` を出力し、細部を圧縮して残したい内容を選んだ。同じMemory群を見たシリカは、逆に記録をそのまま残しておきたいという応答をした。

この差は、Memoryの価値や扱いを固定スコアだけで決めず、住人側の判断対象にできる可能性を考えるきっかけになった。

## Interpretation at the time

この結果だけでReflection、計画、Memory圧縮などの機能が成立したとは判断しない。

観察できたのは、過去を現在の入力として見せた場合に、それらに似て見える出力が発生したことまで。

特にMemory整理の出力は一度の観察であり、再現性やプロンプト依存性は未確認。

## Status

**保留 / 観察継続。**

現時点では、この結果を理由にMemoryの自動整理・削除・統合処理を本体へ追加しない。

## Unknowns

- 同様の出力がどの程度再現するか
- 提示するMemory件数や内容によって何が変わるか
- 住人ごとの差が継続して現れるか
- 自己観察結果をMemoryへ戻した場合に何が起きるか
- 自己観察結果を外部記録（日記など）として残す意味があるか
- Memoryの物理的な上限に達したとき、住人の選択とシステム上の制約をどう分けるか

まだ決めない。
