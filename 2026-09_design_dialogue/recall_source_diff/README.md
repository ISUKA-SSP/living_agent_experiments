# Recall の検索対象に原文を含める/含めないの比較(88入力)

- 対象コード: `living_agent` の `experiments` ブランチ `5bfd74c`
- データ: 2026-09-23〜24 の実際の `memory.db`(Memory 300件)。DB と出力 JSON は会話の全文を含むため、このリポジトリには置いていない。
- 位置づけ: 対談中(2026-09-26)に Claude が行い、メッセージで共有した分析を、あとから追えるように書き直したもの。「通常 Recall から原文を外す方向」の判断材料の一つ。
- [recall_bottleneck_5bfd74c.md](../../2026-09_structure_review/recall_bottleneck_5bfd74c.md) の「想起される内容への影響」(ステラ側の27入力)とは別の、後から行った分析。

## 訂正

対談中は「62入力」と伝えていたが、誤り。62は、上位5件が変わった入力を「観測者と時刻(分単位)」で数えたため、同じ分の発話がまとめられた数だった。正しくは、比較した入力が88回、そのうち上位5件が変わったのが78回。198件などほかの集計値は、同じ結果から出したもので変わらない。

## 条件

- 入力: ステラとシリカそれぞれの Memory にある、自分以外(相手の住人・外部)の発話。同じ発話は1回だけ使う。その発話より前の Memory がない入力は除く。
- 各入力について、その発話より前の Memory だけを対象に、`MemoryRecallService.recall` の上位5件を2通りで比べた。
  - 原文なし: `MemoryRecallService()`。検索対象は `recall_text`(と `recall_keys`)。
  - 原文あり(現行): `MemoryRecallService(perception_renderer=...)`。検索対象は `recall_text`+原文を含む表示+既知名。
- 原文ありで新たに上位5件へ入った Memory について、得点の元になった一致(`_common_text_score` と同じ取り方の断片)を、「`recall_text`・`recall_keys` での一致」と「原文側だけでの一致」に分けた。

## 再現

`living_agent` の `5bfd74c` のチェックアウト直下で実行する(約20秒)。

```
python path/to/recall_source_diff.py memory.db [out.json]
```

スクリプト: [recall_source_diff.py](recall_source_diff.py)。対談中に使った一時スクリプトを1つにまとめ、2026-09-27 に同じ DB で再実行して、下の数値が出ることを確認した。

- 分割された Memory には、どれにも同じ原文全体が付くため、原文ありでは同じ発話からの重複が増える。

## 具体例

**原文が役立ったと言えそうな例**
- 入力(9/23 20:47、シリカ → ステラ):「…新しい何かが始まる予感……か。それって…私たちが揺らぎそのものを受け入れる覚悟を持つってことだよね…」
- 新たに入った Memory(9/23 20:46 のシリカの発言)
  - 解釈:「シリカがステラの言葉の表現力に対し、『存在しない風』が部屋に吹いているかのような感覚を覚えたと伝えた。」
  - 原文の一部:「…懐かしい温もりかな、それとも、新しい何かが始まる予感のような刺激かな。」
- 「新しい何かが始まる予感」(11文字)は原文にしかなく、解釈から抜けた問いかけを原文が拾った。ただし同じ Memory の得点の多くは「。ステラさん」「、ステラさん」「。⏎⏎」などだった。

**口癖・呼び名に引っ張られた例**
- 入力(9/24 19:47、シリカ → ステラ):「日常、かぁ。特別な景色じゃなくて…ねえ、ステラさんもそう思わない? この部屋に、あえて日常の景色が…」
- 新たに入った Memory(9/23 20:49 のシリカの発言、455文字)
  - 解釈:「シリカは、部屋が呼吸する音を『歓迎の合図』や『共犯者』と解釈した。」
  - 一致:「よね。ステラさん」「ねえ、ステラさん」「思わない?」「じゃない」「この部屋」「。⏎⏎」など。解釈側の一致はゼロ。
- 押し出された Memory(直前のイスカの発言)
  - 解釈:「イスカがシリカに日常の景色でいいと話した」
  - 一致:「日常の景色」「イスカ」と、`recall_keys` の「日常」「イスカ」
- 今話している内容に合う Memory が、口癖の一致だけの別の話に押し出された。

## 限界

- 2日分・Memory 300件の小さなデータで、話題も限られる。傾向の参考値であり、会話の収束との因果は示していない。
- 「語尾・呼び名・記号」の分類は簡易ルール(`content_like`)による目安。境界の断片の振り分けで数字は多少動く。
- 解釈側の一致にも「イスカ」「ステラ」「、その」などの呼び名や言い回しが含まれる。原文を外せば偏りは減るが、文字列一致の得点方式そのものが持つ偏りはなくならない。
- 実行時の Recall ではなく、同じ DB を後から読んで再計算したもの。その時点の他者認知(既知名)は現在の DB の値を使っている。
