# Living Agent Experiments

PI = Perfectly Incomplete

I pulled my left lat and had nothing to do.

Living Agentで実際に行った観察・試行の公開記録。

ここでは、後から話をきれいに作り直さない。

- 実際に何をしたか
- 何が出たか
- その時点でどう解釈したか
- 採用したか、保留したか、捨てたか
- まだ分からないこと

を、できるだけ分けて残す。

一度だけ起きたことは、一度だけ起きたこととして書く。再現していない現象を一般化しない。失敗、無反応、想定外の出力も都合よく消さない。

このリポジトリは「成功事例集」ではなく、開発中に何を見て何を考えたかを後から確認するための記録でもある。

Living Agent本体のコードは、現時点ではこのリポジトリには含めない。
